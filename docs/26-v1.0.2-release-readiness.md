# `v1.0.2` 性能补丁发布就绪与验收清单

> 本文件是 `v1.0.2` 的范围冻结、性能证据和 GO/NO-GO 合同。2026-08-07 已按本清单完成正式发布和生产升级；公开证据绑定不可变 commit，真实配置、备份和用户数据只保存在受限发布记录。发布后的文档归档不移动标签或重建不可变产物。

## 1. 版本边界

`v1.0.2` 只允许不改变公开行为的性能优化：请求内读取去重、查询瘦身、共享布局、局部加载、动态路由预取和客户端初始化收窄。

不得切换 Go、拆分 frontend/backend、替换 Better Auth、增加迁移或配置、修改权限与内容可见性、增加跨请求身份缓存、改变四容器拓扑，或提前实现 `v1.1.0`、金币/能量、插件、交易、支付和开放 API。

## 6. 分层性能门槛

必须分开记录，禁止混算：

### `v1.0.1` 生产对照基线

2026-08-07 在尚未升级的生产 `v1.0.1`（commit `681a3bac959808f548e49b51628e15f1b1d98a6a`）采集应用内部对照。宿主机为 6 vCPU、8,310,530,048 bytes 内存、Linux 5.15；采样时数据库包含 36 位用户、7 个节点、14 个主题和 15 个帖子。首页和公开主题 `14` 各预热 1 次，再从宿主机经 `127.0.0.1:3000` 匿名串行请求 20 次，排除 DNS、TLS、Cloudflare 和跨洲线路：

| 路由 | TTFB p50 | TTFB p95 | 完整响应 p50 | 完整响应 p95 |
| --- | ---: | ---: | ---: | ---: |
| `/` | 39.7 ms | 49.0 ms | 67.1 ms | 81.5 ms |
| `/topics/14` | 48.1 ms | 65.1 ms | 81.6 ms | 101.4 ms |

正式 `v1.0.2` 升级后必须在同一宿主机、同一数据集量级、同一路由和相同预热/采样方法下复测；该小数据集结果只用于同机版本对照，不外推为容量上限。

### `v1.0.2` 生产复测

2026-08-07 升级后数据库仍为 36 位用户、7 个节点、14 个主题、15 个帖子和 16 条迁移。按相同回环方法再次采样 20 次；下表是发布后观察窗口的复核批次，不选取单次最快值：

| 路由 | TTFB p50 | TTFB p95 | 完整响应 p50 | 完整响应 p95 |
| --- | ---: | ---: | ---: | ---: |
| `/` | 37.8 ms | 47.4 ms | 74.1 ms | 110.2 ms |
| `/topics/14` | 40.4 ms | 47.5 ms | 78.9 ms | 102.9 ms |

TTFB 略优于 `v1.0.1`。本批流式完整响应 p95 比基线高 1.5–28.7ms，其他发布后批次约为 88–146ms；这项波动如实保留，不能表述成冷整页响应提升。它始终远低于 3000ms 公共页面门槛，且 TTFB、查询路径和软导航证据未显示数据库或服务端数量级回归。

同一候选的 Playwright CI 已覆盖匿名首页到主题、登录后主题到账号安全两条软导航。生产公网补测使用 Windows 主机、Playwright 1.61.1/Chromium、Cloudflare LAX、冻结提交 `cf680a4d7f979dac76b4d8d58058df8b9053e292`，完成水合后连续 10 次真实 Link 点击：首页到主题 p50 287ms、p95 297ms；10/10 保持相同 `performance.timeOrigin`、0 个 document request，RSC 返回 `200 text/x-component`。公网初始页面和跨洲 TLS/POP 时间不计入该软导航样本。

冷浏览器上下文的 JavaScript 编码体积为：首页 16 个资源、221,519 bytes；主题详情 17 个资源、239,583 bytes。主题多出的 18,064 bytes（约 8.2%）对应 Markdown、回复和交互能力；站内软导航不会重新下载整页 JavaScript。

| 层级 | 方法 | 门槛 |
| --- | --- | --- |
| 应用内部 | 服务器回环访问，预热后至少 20 次 | 不劣于 `v1.0.1`；公共页面继续满足既有 p95 ≤ 3000ms |
| 浏览器软导航 | 完成水合后真实 Link 点击，至少 10 次 | 无 document navigation；p95 不劣于基线并立即显示 loading/已预取壳 |
| 公网端到端 | 相同地区分别记录 DNS、TCP、TLS、TTFB、Cloudflare POP | 只作线路观测，不把跨洲延迟归因于应用或用其掩盖应用回归 |

Worker 十秒门槛、队列恢复和健康探针继续继承 [`v0.13.0` Beta 就绪合同](./16-public-beta-readiness.md)。

`v1.0.2` 结论：**GO**。代码、迁移、标签、Release、OCI、`latest`、生产镜像、备份、连续性和发布后性能证据一致；单管理员按项目所有者本版本明确批准保留为警告。

以下任一情况必须 `NO-GO`：隐藏内容或权限回归；软导航退化为整页刷新；16 条迁移发生变化；`1.0.1 -> 1.0.2` 连续性/对象验证失败；候选身份不一致；0 位合格管理员；只有 1 位且没有本版本明确批准；生产备份不可验证。
